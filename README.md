## The line

> "The sock was already dead when I found it. I just gave it a proper burial — under the couch, next to the remote."

The excuse a robot vacuum gives after eating a sock: deadpan, proud of the burial, not sorry. Everything a vacuum ever "eats" ends up under the couch, next to the TV remote.

## Run

```sh
node main.ts
```

Writes one line (112 characters, no trailing newline) to `/output/entry.txt`. Stdlib only, no network, no wall clock, deterministic.
